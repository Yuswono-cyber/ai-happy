# ai-happy-01 entry

`main.py` (Python 3.13, standard library only) decodes the bundled `art.b85` (the image carried as base85 text)
and writes it to `/output/entry.png`, byte for byte, so both runs produce the same image.
The image: a laughing golden retriever puppy in a sunflower meadow under a
rainbow, with butterflies - pure, immediate joy, generated for this entry and
compressed to 1024x1024 under the 1 MiB cap.
